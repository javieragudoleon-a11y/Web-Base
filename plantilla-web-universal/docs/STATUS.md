# Estado de plantilla maestra LEOVEX v2.0

- Arquitectura original conservada: HTML/CSS/JS, Node sin dependencias, Pages Functions opcionales.
- Configuración, cuatro temas, SEO local JSON-LD, galería, WhatsApp, formulario opcional, 404 y controles de preview/producción implementados.
- `npm run qa`: 19 pruebas automáticas superadas (Node 22). Las llamadas a Turnstile y Resend se simulan en tests.

La navegación por servidor local quedó bloqueada por el entorno de pruebas; se cargó HTML/CSS/JS de forma local en el navegador.
- Estado inicial: demostración, sin indexación, sin formulario, sin datos reales. No publicada.
